## 🎯 Repository Purpose & Architecture
`QuestionPaperAI` is an intelligent assessment generation platform featuring OCR scan pipelines, curriculum taxonomy mapping, and multi-difficulty question synthesis adhering to strict pedagogical schemas.

### Tech Stack
- **Frontend & Server**: React 18, TypeScript, Express, Drizzle ORM
- **OCR Service**: Python OCR scan service
